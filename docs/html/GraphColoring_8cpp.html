Splits a web's live range at its midpoint.

The original web keeps intervals and program points at or before the split point. A new web (with incremented ID and label suffixed with "_s") receives the remainder. Intervals spanning the split point are divided.

Parameters
websThe vector of all webs (the new web is appended).
idxIndex in webs of the web to split.
nextIdThe next available web ID (incremented after creating the new web).
entryOutput tuple populated as (originalId, newWebId, splitPoint).
