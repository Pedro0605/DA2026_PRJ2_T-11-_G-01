49/**
50 * @brief Implements graph coloring algorithms for register allocation.
51 *
52 * Provides static methods for Chaitin-style basic coloring, coloring
53 * with spilling heuristics, live-range splitting, and custom
54 * (Welsh-Powell) allocation.
55 */
56class GraphColoring {
57public:
58 /**
59 * @brief Performs basic Chaitin-style graph coloring.
60 * @details
61 * Phase 1 (Simplify): repeatedly pushes nodes with degree < K onto a stack and
62 * removes them from the graph. If no such node exists, coloring fails.
63 *
64 * Phase 2 (Select): pops nodes from the stack and assigns the lowest
65 * available color not used by any already-colored neighbor.
66 *
67 * @par Time complexity
68 * O(V^2) where V is the number of vertices. The simplify phase may iterate
69 * over all remaining vertices per round (O(V^2) worst-case), and the select
70 * phase processes each vertex once, checking up to K colors (O(V*K)).
71 *
72 * @param ig The interference graph.
73 * @param K Number of available colors (registers).
74 * @param colorAssignment Output map from vertex ID to assigned color.
75 * @return True if the graph was successfully K-colored, false otherwise.
76 */
77 static bool basicColoring(Graph<int>& ig, int K,
78 std::unordered_map<int, int>& colorAssignment);
79
80 /**
81 * @brief Performs graph coloring with iterative spilling.
82 * @details
83 * Attempts basic coloring; if it fails, selects the vertex with the highest
84 * effective degree (the "worst" node), marks it for spilling, and retries.
85 * This process repeats until either a successful coloring is found or the
86 * maximum number of spills is reached (or all vertices are spilled if no limit).
87 *
88 * @par Time complexity
89 * O(S * V^2) where V is the number of vertices and S is the number of
90 * spilled vertices. In the worst case S = V, giving O(V^3).
91 *
92 * @param ig The interference graph.
93 * @param K Number of available colors (registers).
94 * @param colorAssignment Output map from vertex ID to assigned color.
95 * @param spilledWebs Output vector of vertex IDs that were spilled to memory.
96 * @param maxSpills Maximum number of webs to spill (default: -1 = unlimited).
97 * @return True if coloring succeeded after spilling, false otherwise.
98 */
99 static bool coloringWithSpilling(Graph<int>& ig, int K,
100 std::unordered_map<int, int>& colorAssignment,
101 std::vector<int>& spilledWebs,
102 int maxSpills = -1);
103
104 /**
105 * @brief Performs graph coloring with live-range splitting.
106 * @details
107 * Attempts basic Chaitin coloring on the current set of webs. If coloring fails,
108 * the highest-degree web is split at the midpoint of its live range, reducing
109 * interferences. The process repeats until success or the split budget is exhausted.
110 *
111 * @par Time complexity
112 * O(S * V^3) where V is the initial number of webs and S is the number of splits
113 * performed. Each iteration rebuilds the interference graph and re-runs basic
114 * coloring (O(V^2) per iteration for the graph build, O(V^2) for coloring).
115 *
116 * @param webs The vector of webs (may grow as splits create new webs).
117 * @param K Number of available registers.
118 * @param maxSplits Maximum number of splits allowed.
119 * @param colorAssignment Output map from web ID to assigned color.
120 * @param splitLog Output log of splits performed, each entry is a tuple
121 * (originalWebId, newWebId, splitPoint).
122 * @return True if the graph was successfully K-colored, false otherwise.
123 */
124 static bool coloringWithSplitting(std::vector<Web>& webs, int K, int maxSplits,
125 std::unordered_map<int, int>& colorAssignment,
126 std::vector<std::tuple<int, int, int>>& splitLog);
127
128 /**
129 * @brief Performs custom graph coloring using the Welsh-Powell algorithm.
130 * @details
131 * Sorts vertices by degree in descending order and colors them greedily to minimize
132 * register usage. Any vertices that cannot be colored with the available registers
133 * are spilled to memory.
134 *
135 * @par Time complexity
136 * O(V * log V + V^2 * K) where V is the number of vertices and K is the number
137 * of available colors (registers).
138 *
139 * @param graph Pointer to the interference graph.
140 * @param maxRegisters Number of available colors (registers).
141 * @return Map linking each web to its assigned register ("rX") or memory ("M").
142 */
143 template <class T>
144 static std::map<T, std::string> allocateRegistersFree(Graph<T>* graph, int maxRegisters);
145};
