Detailed Description

Implements graph coloring algorithms for register allocation.

Provides static methods for Chaitin-style basic coloring, coloring with spilling heuristics, live-range splitting, and custom (Welsh-Powell) allocation.

Performs custom graph coloring using the Welsh-Powell algorithm.

Implementation of GraphColoring::allocateRegistersFree.

Sorts vertices by degree in descending order and colors them greedily to minimize register usage. Any vertices that cannot be colored with the available registers are spilled to memory.

Time complexity
O(V * log V + V^2 * K) where V is the number of vertices and K is the number of available colors (registers).
Parameters
graphPointer to the interference graph.
maxRegistersNumber of available colors (registers).
Returns
Map linking each web to its assigned register ("rX") or memory ("M").

Performs basic Chaitin-style graph coloring.

Implementation of GraphColoring::basicColoring.

Phase 1 (Simplify): repeatedly pushes nodes with degree < K onto a stack and removes them from the graph. If no such node exists, coloring fails.

Phase 2 (Select): pops nodes from the stack and assigns the lowest available color not used by any already-colored neighbor.

Time complexity
O(V^2) where V is the number of vertices. The simplify phase may iterate over all remaining vertices per round (O(V^2) worst-case), and the select phase processes each vertex once, checking up to K colors (O(V*K)).
Parameters
igThe interference graph.
KNumber of available colors (registers).
colorAssignmentOutput map from vertex ID to assigned color.
Returns
True if the graph was successfully K-colored, false otherwise.

Performs graph coloring with iterative spilling.

Implementation of GraphColoring::coloringWithSpilling.

Attempts basic coloring; if it fails, selects the vertex with the highest effective degree (the "worst" node), marks it for spilling, and retries. This process repeats until either a successful coloring is found or the maximum number of spills is reached (or all vertices are spilled if no limit).

Time complexity
O(S * V^2) where V is the number of vertices and S is the number of spilled vertices. In the worst case S = V, giving O(V^3).
Parameters
igThe interference graph.
KNumber of available colors (registers).
colorAssignmentOutput map from vertex ID to assigned color.
spilledWebsOutput vector of vertex IDs that were spilled to memory.
maxSpillsMaximum number of webs to spill (default: -1 = unlimited).
Returns
True if coloring succeeded after spilling, false otherwise.

Performs graph coloring with live-range splitting.

Implementation of GraphColoring::coloringWithSplitting.

Attempts basic Chaitin coloring on the current set of webs. If coloring fails, the highest-degree web is split at the midpoint of its live range, reducing interferences. The process repeats until success or the split budget is exhausted.

Time complexity
O(S * V^3) where V is the initial number of webs and S is the number of splits performed. Each iteration rebuilds the interference graph and re-runs basic coloring (O(V^2) per iteration for the graph build, O(V^2) for coloring).
Parameters
websThe vector of webs (may grow as splits create new webs).
KNumber of available registers.
maxSplitsMaximum number of splits allowed.
colorAssignmentOutput map from web ID to assigned color.
splitLogOutput log of splits performed, each entry is a tuple (originalWebId, newWebId, splitPoint).
Returns
True if the graph was successfully K-colored, false otherwise.
