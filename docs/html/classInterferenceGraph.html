Detailed Description

Builds and manages the interference graph from a set of webs.

The interference graph is an undirected graph where each vertex represents a web and edges connect webs whose live ranges overlap.

void InterferenceGraph::build ( const std::vector< Web > & webs)

Builds the interference graph from a list of webs.

Implementation of InterferenceGraph::build.

For each pair of webs, an edge is added if their live ranges overlap.

Time complexity
O(V^2) where V is the number of webs, since every pair is checked.
