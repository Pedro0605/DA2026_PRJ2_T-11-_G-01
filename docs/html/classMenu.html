Detailed Description

Interactive CLI menu for the Global Register Allocator.

Provides a console-based interface for loading input files, running allocation algorithms (basic, spilling, splitting, custom), viewing results, and writing output. Also supports automatic execution based on configuration loaded from the registers file.
