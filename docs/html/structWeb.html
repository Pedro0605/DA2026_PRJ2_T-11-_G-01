Detailed Description

Represents a web (a live range variable) in the register allocation problem.

Each web has a unique identifier, a set of live range intervals, a label, program points, and an assigned resource (register name or "M" for memory).

bool Web::interferesWith ( const Web & other) const
inline

Checks whether this web interferes with another.

Two webs interfere if any of their live range intervals overlap, excluding boundary-only overlaps where one ends with '-' and the other starts with '+' at the same line (per spec non-interference rule).

Time complexity
O(I1 * I2 * P) where I1, I2 are the number of live range intervals in each web, and P is the number of program points per web (for marker lookups).
Parameters
otherThe other web to check against.
Returns
True if the webs interfere, false otherwise.
